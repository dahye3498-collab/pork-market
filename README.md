# 돈육 시세노트

공개 서비스: https://dahye3498-collab.github.io/pork-market/

GitHub Pages는 `public/dashboard/` 화면과 수집된 JSON만 게시합니다. API 인증키는 GitHub Actions의 `EKAPE_API_KEY` Secret에 보관합니다. `.github/workflows/pages.yml`이 최초 최근 62일, 이후 최근 7일을 다시 조회해 정정 자료를 반영하며 기존 날짜는 보존합니다. 한국시간 매일 10:10·18:10에 실행 예정이며 GitHub 사정에 따라 지연될 수 있습니다. 수집 실패 시 기존 게시 자료를 유지합니다. 수동 실행의 days 입력으로 최대 90일까지 재수집할 수 있습니다.

Pages 화면은 저장 자료를 읽으므로 방문자가 API를 직접 호출하지 않습니다. 수집 성공한 미거래일과 수집되지 않은 날짜를 구분합니다. 아래 서버 실행 안내는 기존 Sites 개발 환경에 해당합니다.

축산물품질평가원의 돼지도체 등급별 경락가격 API를 조회하고 날짜별 시세와 경락두수를 기록하는 개인용 웹사이트입니다.

## 기능

- 접속 시 전일까지 최근 30일 자동 조회, 최근 30일·지난달 버튼, 최대 31일 선택 조회
- 최대 3일 동시 수집, 진행률 표시, 미거래일과 실패일 구분, 일부 실패 시 성공한 자료 보존
- 탕박·박피 동시 조회 또는 개별 조회, 같은 날짜의 모돈 비교 표 및 카톡 요약
- 날짜·성별·돈피·등급별 가격, 두수와 지역 비교
- 누적 가격 그래프, 이전 기록 대비 변화
- 카톡 요약 복사, XML 가져오기, JSON 백업 및 복원

## API 비밀 설정

서버 환경변수 `EKAPE_API_KEY`에 공공데이터포털에서 발급한 키를 설정합니다. 일반 인증키와 URL 인코딩된 키를 지원합니다. 키를 저장소나 프런트엔드 코드에 넣지 마세요. `.env.example`에는 이름만 기재되어 있습니다. Sites에서는 런타임 비밀 설정 후 다시 게시해야 적용됩니다.

API: `http://data.ekape.or.kr/openapi-data/service/user/grade/auct/pigGrade`

요청 항목: `serviceKey`, `startYmd`, `endYmd`, `skinYn`, `sexCd`. 날짜는 하루씩 조회하며 기간 합산값을 일별 가격으로 사용하지 않습니다. 서버 연결은 `/api/status`로 설정 유무만 확인하고 `/api/prices`에서 실제로 호출합니다. 서버 응답은 허용한 가격 필드만 반환합니다.

## 실행과 확인

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run dev
node --test tests/pork-api.test.mjs
node --test tests/month.test.mjs
npm run build
```

로컬 개발은 Sites 기본 인증 모의 설정을 사용합니다. Sites의 운영 API는 로그인한 사용자만 사용할 수 있습니다. 공개 Pages에는 서버 API와 인증키가 포함되지 않습니다.

## 자료 기준

자료 출처: 축산물품질평가원. [API 안내](https://www.data.go.kr/data/15058822/openapi.do)

`CTotAmt/Cnt`는 전국, `c_1101eTotAmt/Cnt`는 제주 제외, `CCityAmt/Cnt`는 수도권, `CEastAmt/Cnt`는 영남권, `c_0513Amt/Cnt`는 농협음성 집계입니다. 공식 돼지도체 등급별 경락가격 기능 명세로 확인했습니다. 평균과 등외제외 행은 구분하며 모돈은 모돈 행만 사용합니다. 암거세 합산은 공식 집계 정의 확인 전까지 생성하지 않습니다. 성별 코드는 실제 조회 결과의 성별과 함께 확인해야 합니다.

샘플은 제공된 2016-01-20 암컷·탕박 응답이며 최신 시세가 아닙니다. 조회 자료는 해당 브라우저의 localStorage에 저장됩니다. 다른 기기와 자동 동기화하지 않으며 JSON 내보내기로 백업할 수 있습니다. 같은 날짜·성별·돈피·등급은 갱신합니다. 미거래와 누락은 0원으로 대체하지 않습니다.

가격은 원/kg, 두수는 두입니다. 이전 기록 대비는 반드시 직전 경매일 대비를 의미하지 않습니다. 당일 잠정 자료는 재수집으로 갱신합니다. 첫 접속 시 성별 전체·탕박과 박피 둘 다로 최근 30일을 조회합니다. 그래프는 선택 조회기간부터 선택 날짜까지 표시하며 샘플을 실제 기록과 섞지 않습니다. Pages의 자료는 사이트가 닫혀 있어도 GitHub에서 정기 수집합니다.
