API 연결 상태와 데이터 기준

API 조회는 서버에서 처리하며 인증키는 화면에 표시하거나 브라우저에 저장하지 않습니다. API 연결 상태는 위 조회 영역에서 확인할 수 있습니다.

전국·수도권·영남권·음성은 API 제공 집계값을 사용합니다. 제주 제외는 API의 제주제외전체 집계값을 사용합니다. 모돈은 API의 ‘모돈’ 행만 사용합니다.

‘평균’과 ‘등외제외’는 서로 다른 항목입니다. 전일 비교는 동일 성별·돈피·등급의 가장 가까운 이전 기록과 비교하며, 직전 경매일인지 확인되지 않으면 ‘이전 기록 대비’로 표시합니다. 기간 합산 응답은 일별 추이로 저장하지 않습니다.
